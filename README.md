# City Zoo — Assignment #3 (Media Queries + Bootstrap Grid)

**Team:** Jumabay Saule, Ramazan Mukhan, Nurdaulet Rashken, Saidazimov Mukhammadjan — Group SE-2501

This project builds on the City Zoo site from Assignment #2. Its original green color palette and visual style are retained. The separate Media Queries page has been removed; responsive typography and card-layout work are shown on the existing pages.

| Task | Where it is demonstrated |
|------|--------------------------|
| 1. Responsive typography | `css/style.css`; headings and paragraphs on `index.html` and other pages |
| 2. Three cards: 1 on mobile, 2 on tablet, 3 on desktop | `index.html` (`.why-visit-grid` in `css/style.css`); layout uses CSS media queries, not Bootstrap Grid |
| 3. Bootstrap grids (`col-lg-6` and `col-lg-4`) | `index.html` (two-column section and three-column stats row) |
| 4. Bootstrap spacing utilities | All Bootstrap pages use `m-*`, `p-*`, responsive spacing, and `gap-*` utilities; theme CSS has no custom margin or padding rules |
| 5. Responsive Bootstrap navbar with hamburger | Every HTML page |
| 6. Bootstrap buttons, outline/size variants, and a button group | `index.html`, `animals.html`, `tickets.html`, `contact.html` |
| 7. Carousel with 9 images, indicators, and controls | `animals.html` |
| 8. Bootstrap cards with images, titles, and descriptions in a card group/grid | `index.html`, `animals.html`, `tickets.html`, `about.html` |
| 9. Responsive Bootstrap form | `contact.html` |
| 10. Semantic HTML and accessibility | All pages: landmarks, skip links, labelled controls, image alt text, focus styles, and contrast |
